# Fotos

Coloque as fotos originais aqui, uma pasta por serviço (o nome da pasta é o slug):

- `fundo/` — imagem de fundo do topo da home
- `desentupimento-de-pia/`
- `desentupimento-de-vaso-sanitario/`
- `desentupimento-de-ralo/`
- `desentupimento-de-esgoto/`
- `limpeza-de-caixa-de-gordura/`
- `desentupimento-de-tanque/`
- `desentupimento-de-coluna/`
- `hidrojateamento/`

No build, a primeira foto de cada pasta vira `src/assets/fotos/<slug>.jpg` (otimizada).
Para trocar uma foto, apague o `.jpg` gerado em `src/assets/fotos/`.

O logo vai em `src/assets/logo.png`.
